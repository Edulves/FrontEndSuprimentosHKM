## Brand & Style

The design system is engineered for mission-critical enterprise procurement, strategic sourcing, and supply chain logistics operating in Portuguese-speaking global enterprises. The platform targets procurement directors, supply chain analysts, category managers, and inventory controllers who manage multi-million-currency vendor contracts, complex purchase orders, and real-time fulfillment pipelines.

### Design Movement: Modern Corporate Precision
The aesthetic blends **Modern Corporate** structure with **Swiss Graphic Functionalism**:
- **Utilitarian Clarity**: High information density without visual chaos. Chrome is subdued to let operational data (SKUs, purchase orders, status tallies, unit economics) lead.
- **Architectural Rigor**: Clean bounding borders, disciplined column alignment, and zero arbitrary decorative motifs.
- **Cognitive Ergonomics**: Immediate status recognition through functional semantic cues, minimizing operator fatigue over 8-hour operational shifts.
- **Tone**: Authoritative, dependable, razor-sharp, and uncompromised in stability and clarity.

## Colors

The color palette is built for clarity, institutional gravity, and actionable contrast in dense operational environments.

### Primary & Brand Anchors
- **Primary Industrial Blue (`#0D5BFF`)**: The interactive focal point. Used strictly for core call-to-actions, active navigation selection, focus rings, and primary interactive links.
- **Deep Slate Navy (`#0F1E36`)**: The institutional anchor. Applied to top-level headers, primary text, high-level navigation chrome, and structural dividers.

### Supporting Semantics
- **Emerald Procurement Success (`#0E8A5F`)**: Direct validation for approved purchase orders, healthy stock indicators, and fully matched 3-way invoices. Paired with soft tint backgrounds (`#E8F7F0`).
- **Amber Warning & Caution (`#D97706`)**: Applied to pending approvals, customs holds, SLA risks, and partial shipments. Paired with soft warning tint (`#FEF3C7`).
- **Critical Red Alert (`#DC2626`)**: Reserved for stockouts, rejected requisitions, compliance failures, and contractual disputes. Paired with soft tint (`#FEE2E2`).

### Cool Gray Neutral Scale
- **Canvas Base (`#F8FAFC`)**: Ultra-light cool slate foundation for application backdrops.
- **Surface Elevation 0 (`#FFFFFF`)**: Pure white card layers, tables, and modal backgrounds.
- **Surface Elevated Tier (`#F1F5F9`)**: Table header strips, inner inset boxes, and disabled components.
- **Border Subtle (`#E2E8F0`)**: Hairline boundary lines between dense tabular rows and structural layout splitters.
- **Border Strong (`#CBD5E1`)**: Input outlines and segmented control boundaries.
- **Text Primary (`#0F172A`)**: Primary data points, values, and headings.
- **Text Secondary (`#475569`)**: Metadata, table headers, labels, and helper notes.
- **Text Muted (`#94A3B8`)**: Placeholder values, inactive step icons, and disabled states.

## Typography

The typography leverages **Inter** across all roles to maximize legibility in data-dense layouts.

### Implementation Principles
- **Portuguese Localization**: Text layout engines must accommodate an average expansion of +15% to +25% character count relative to English (e.g., "PO Status" becomes "Status do Pedido de Compra"; "Vendor" becomes "Fornecedor Homologado"). Labels and table headers must not truncate abruptly; prioritize multi-line allowances over ellipsis.
- **Tabular Figures**: All financial figures (`BRL / R$`, `USD / $`, `EUR / €`), volumes, quantities, dates, and order identifiers (`PO-#891204`) must enforce `font-feature-settings: "tnum" 1, "cv05" 1` (tabular numerals) to ensure vertical column alignment across comparative matrices.
- **Visual Weighting**: Table column headers leverage `label-md` uppercase with `0.02em` tracking and muted contrast (`#475569`) to distinguish structural metadata from active row contents.

## Layout & Spacing

The layout philosophy follows a **fluid responsive multi-pane dashboard model** based on a rigorous 4px baseline grid.

### Layout Architecture
- **Desktop (≥1280px)**: 
  - Persistent collapsible left navigation rail (64px collapsed, 240px expanded).
  - Main operational workspace: Fluid 12-column grid system with `gutter-lg` (1.5rem / 24px) and page margins of `margin-lg` (2rem / 32px).
  - Contextual sliding right drawer panel (480px) for transaction deep dives, audit logs, and workflow approval histories without leaving context.
- **Tablet (768px - 1279px)**:
  - Navigation converts to an off-canvas drawer.
  - Workspace scales to an 8-column layout with `gutter` (1rem / 16px) and `margin-md` (1.5rem / 24px).
  - Data tables enable horizontal panning with fixed sticky columns for primary keys (`ID do Pedido`, `Fornecedor`).
- **Mobile (<768px)**:
  - 4-column layout with `margin` (1rem / 16px). Table views collapse into stacked cards with segmented metric layouts.

### Spacing Density Principles
- Compact structural density: Data grid cell padding is fixed at vertical `space-sm` (8px) and horizontal `space-md` (12px) to maximize row visibility above the fold.
- Form field stacks and input groups use `space-md` (12px) internal gaps, while major card modules use `space-xl` (24px) margins.

## Elevation & Depth

The design system uses **flat tonal layering paired with low-contrast structural outlines**, deliberately rejecting dramatic drop shadows to preserve contrast for mission-critical data.

### Elevation Hierarchy
- **Level 0 (Flat Canvas)**: Background canvas (`#F8FAFC`). No elevation or border.
- **Level 1 (Structural Containers)**: Primary data tables, metric cards, and form containers. Background `#FFFFFF` with a 1px border of `#E2E8F0`. Subtle ambient grounding shadow: `0 1px 3px 0 rgba(15, 30, 54, 0.04)`.
- **Level 2 (Popovers, Filter Menus, Dropdowns)**: Background `#FFFFFF`, 1px border of `#CBD5E1`, and focused floating shadow: `0 4px 12px 0 rgba(15, 30, 54, 0.08), 0 1px 2px 0 rgba(15, 30, 54, 0.04)`.
- **Level 3 (Modals & Sliding Inspection Panels)**: Modals and flyout drawer sheets (`#FFFFFF`) sitting atop a backdrop tint of `#0F1E36` with 45% opacity. Shadow: `0 12px 32px -4px rgba(15, 30, 54, 0.16)`.

## Shapes

The design system employs **Level 1 (Soft)** geometry. Procurement platforms demand structured, professional stability; excessive roundedness consumes critical pixels and compromises data density.

### Radius Assignments
- **Micro Radii (`0.125rem` / 2px)**: Checkbox marks, nested progress sub-bars, and data cell indicators.
- **Standard Control Radii (`0.25rem` / 4px)**: Buttons, text inputs, dropdown triggers, search containers, table row selection badges, and status pills.
- **Panel & Container Radii (`0.5rem` / 8px)**: Primary metric overview cards, high-level tables, configuration cards, and modal dialog boxes.
- **Flyout Radii (`0.75rem` / 12px)**: Large overlay drawers and floating notification banners.

## Components

### Buttons & Interactive Controls
- **Primary Button**: Background `#0D5BFF`, label `#FFFFFF`, font `Inter` 14px weight 600. Height 36px (compact) / 40px (regular). Hover: `#0047DB`. Active: `#0039B3`. Focus ring: 2px offset with `#0D5BFF` at 40% alpha.
- **Secondary / Neutral Button**: Background `#FFFFFF`, border 1px solid `#CBD5E1`, text `#0F172A`. Hover: `#F8FAFC` and border `#94A3B8`.
- **Destructive Action Button**: Background `#FFFFFF`, border 1px solid `#FCA5A5`, text `#DC2626`. Hover: background `#FEE2E2`.
- **Text / Ghost Button**: Transparent background, text `#475569`, hover background `#F1F5F9`.

### Data Tables (Tabelas de Suprimentos)
- **Header**: Background `#F8FAFC`, height 40px, bottom border 1px solid `#E2E8F0`. Typography `label-md` in uppercase, color `#475569`.
- **Rows**: Alternating hover state with `#F8FAFC`. Minimum row height 44px for high density, 56px for standard items. Border bottom 1px solid `#F1F5F9`.
- **Inline Numeric Values**: Tabular lining figures, right-aligned with column headers matching right alignment.
- **Selection State**: Row background shifts to `#EFF6FF` with a 2px left border strip of `#0D5BFF`.

### Search & Faceted Filter System
- **Global Search Bar**: Height 40px, border 1px solid `#CBD5E1`, background `#FFFFFF`, leading search icon (`#627084`), trailing keyboard shortcut badge (`⌘K` / `Ctrl+K`).
- **Filter Chips (Filtros Aplicados)**: Removable tags with height 28px, background `#F1F5F9`, border 1px solid `#E2E8F0`, label `body-sm` (`#334155`), with an integrated dismiss "x" icon (`#64748B`) that darkens on hover.
- **Dropdown Filter Triggers**: Chevron-down accompanied by dynamic active counter badges (e.g., `Fornecedor (3)`).

### Badges & Status Indicators
Badges feature an 8px circular indicator dot paired with text in `label-sm` weight 600, height 24px, padding 0 8px, border radius 4px:
- **Aprovado / Em Trânsito (Success)**: Background `#E8F7F0`, text `#0E8A5F`, dot `#0E8A5F`.
- **Pendente de Aprovação (Warning)**: Background `#FEF3C7`, text `#B45309`, dot `#D97706`.
- **Cancelado / Risco de SLA (Critical)**: Background `#FEE2E2`, text `#B91C1C`, dot `#DC2626`.
- **Rascunho / Arquivado (Neutral)**: Background `#F1F5F9`, text `#475569`, dot `#94A3B8`.

### Input Fields & Form Controls
- **Text Inputs**: Height 38px, font 14px, background `#FFFFFF`, border 1px solid `#CBD5E1`, placeholder `#94A3B8`. Focus: border `#0D5BFF`, ring 3px of `rgba(13, 91, 255, 0.15)`.
- **Error State**: Border `#DC2626`, focus ring 3px of `rgba(220, 38, 38, 0.15)`, error message below in 12px `#DC2626`.
- **Checkboxes & Radios**: 16x16px boxes. Unchecked: border 1px solid `#94A3B8`. Checked: solid `#0D5BFF` with crisp white SVG check/dot icon.

### Metric Overview Cards (KPI Cards)
- Metric container with white background, 1px border `#E2E8F0`, padding 16px.
- Top row: Metric title in `label-md` (`#475569`) with optional tooltip trigger.
- Middle row: Metric value in `headline-lg` (`#0F172A`) formatted as Portuguese currency or integer (`R$ 1.240.500,00`).
- Bottom row: Comparison trend pill displaying percentage change (e.g., `+12.4% vs. mês anterior`) in green or red text accompanied by a micro directional arrow icon.
